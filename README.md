# Susan Currie Sivek, Ph.D., Portfolio Site

Hi, I'm Susan. I used to teach journalism and study media for a living — now I write about AI platforms for one, as a Principal Product Marketing Manager at Kinaxis. Before my current adventure, I picked up stints at Alteryx, Pecan AI, and Blue Yonder, too, so this archive is what happens when a journalism professor keeps writing anyway, just about supply chains and AI instead of media theory.

This repo is that archive: 300+ published pieces — journalism, research, whitepapers, blog posts, case studies — coded up with Claude and Cursor. It's what I've built, said, and shipped over the years, in one place, for free, forever (or at least until GitHub goes the way of Friendster).
